# 课镜研究工作台开发说明 V1.0

## 研究任务与实现范围

当前原型面向有字幕网课，组织多模态数据准备、教学快照弹幕整体状态评估、有字幕视频分段与片段反馈分析三项核心内容。主工作流为课程来源登记、素材获取或导入、字幕检查、B站原生播放器截屏、片段组织、报告填写、复核与导出。

本轮实现基本原型。分类标准、快照模型、分段研究模型和片段聚合模型在方案确定后接入；报告框架与人工内容明确区分。原有课程发布、学生注册和发弹幕页面已退出运行入口。

## 页面与调用链

1. `src/data_server.py` 启动 `src/research_server.py`，只在 `127.0.0.1` 监听。
2. `web/research.html`、`research.js`、`research.css` 提供四个工作区：素材与采集、原始快照、教学片段、报告与复核。
3. `ResearchStore` 在 `outputs/research/<任务编号>/` 管理来源、素材、字幕、片段、原图、报告和修订。上传原图保留原始字节及SHA-256校验值。
4. B站获取复用 `fetch_course.fetch`，保存课程视频、弹幕XML与规范化JSON。`fetch_bilibili_subtitles` 调用B站字幕接口，优先选取 `ai-zh`，其次为B站提供的其他中文字幕轨道。
5. `integrations/bilibili-capture` 在用户当前B站页面中定位播放器，通过浏览器截图接口截取实际显示区域，再以任务专属配对凭据回传本机。
6. `ResearchStore.run` 建立固定报告字段并关联快照和片段；自动分析字段为空。人工填写保存为独立修订，记录原因、时间、原报告与修订内容。

## 原生B站快照采集

采集直接使用B站网页播放器。视频、字幕和弹幕由原平台显示，采集器只控制播放定位并裁切播放器区域。采集器不会用下载的视频、字幕和弹幕重新绘制截图。

使用前在B站页面开启中文字幕与弹幕。扩展在目标时间之前预播放最多2秒，使播放器有时间呈现动态弹幕，然后暂停并等待中文字幕连续稳定1秒。实际时间与请求时间的偏差须在0.5秒以内；截图时再次核对暂停状态、实际时间和前台标签页。具体等待参数属于工程初值，后续依据真实页面试验调整。

每张截图保存来源URL、分P、请求时间、实际时间、视频时长、字幕文本、字幕稳定检查、播放器裁切边界、视口参数、弹幕DOM数量或画布存在信息、采集时间及图片校验值。弹幕画布存在只说明显示层存在，实际可见条数、遮挡和读取质量由原图复核。

字幕未显示、字幕不稳定、定位超时、页面切换、播放器显示不完整或来源分P不一致时，该时间点失败并保留提示。使用者调整页面后可以重试。语音转写与本地弹幕重绘均未接入当前采集主线。

### 安装与试用

1. 启动本地工作台，建立含B站视频链接的研究任务，填写获准使用范围。
2. 在Chrome的 `chrome://extensions` 或Edge的 `edge://extensions` 中开启开发者模式，选择“加载已解压的扩展程序”，选中本仓库的 `integrations/bilibili-capture` 目录。
3. 在工作台生成采集配对配置，打开任务对应的B站页面，登录并选择中文字幕，开启弹幕。
4. 点击课镜采集扩展，粘贴配置、填写采集秒数并开始。保持该B站窗口处于前台；一次最多30个时间点，配置一小时有效。
5. 回到工作台刷新，逐张核对课程内容、字幕、弹幕、实际时间与遮挡。失败时间点在扩展进度中查看后重试。

扩展使用 `activeTab`，权限由使用者在当前标签页点击扩展时授予；脚本仅在BV视频页面执行。配对凭据只允许向当前任务回传截图，不提供文件系统或通用命令执行权限。扩展不读取或导出B站Cookie。工作台的二维码登录独立用于素材和字幕获取，凭据留在本地服务内存中。

实现依据：[Chrome Tabs API](https://developer.chrome.com/docs/extensions/reference/api/tabs)、[Chrome Scripting API](https://developer.chrome.com/docs/extensions/reference/api/scripting)、[扩展消息通信](https://developer.chrome.com/docs/extensions/develop/concepts/messaging)。B站字幕适配参考[yt-dlp的Bilibili提取器](https://github.com/yt-dlp/yt-dlp/blob/master/yt_dlp/extractor/bilibili.py)；平台接口和页面结构变化时需重新验证。

## 字幕与片段

字幕支持SRT、VTT、JSON `segments` 和B站 `body` 格式。系统检验非空文本、有限数值、起止关系、视频范围、顺序和重叠，并按时间区间并集计算覆盖率。字幕文本准确性和术语识别质量保留人工检查。

当前候选边界使用字幕章节表达、停顿和最长片段时长规则，页面明确标为规则候选。用户可调整标题和起止时间；保存时要求连续、不重叠并完整覆盖视频。该工程基线尚未复现Chapter-Llama、MMVTS或其他研究方法。快照按实际时间归入片段，缺少快照的片段显示数量为0，等待补采。

## 报告与数据接口

### 模型连接与运行方式

　　侧栏保留通用大模型 API、本地模型、校园服务器三种选择。运行方式写入任务输入的 `model_provider`，创建任务时沿用当前选择，已有任务通过“将运行方式保存到当前任务”更新。JSON导出包含该字段，模型执行记录继续由报告的 `model` 字段单独承载，当前值为 `null`。由此可追踪运行方式的选择，同时清楚区分连接准备与实际模型执行。

　　通用大模型 API 复用 `api_settings.py`，保留服务商与官方接口地址、API Key、模型列表、手动模型 ID、输出协议、文本与图文探测、Token用量记录、支持服务商的余额查询及清除 Key。文本与图文探测使用合成指令和合成图片，调用由使用者发起，可能产生费用；更换模型后重新验证。Key仅保存在本次后端服务内存中，页面保存后清空输入，任务和导出记录保存非敏感的运行方式。

　　本地方式复用 `model_providers.py` 中的 `qwen35-4b` 配置与 `local_model.py` 的服务检查，通过 `start-local-demo.ps1` 启动现有本地权重和工作台。校园方式读取 `COURSE_CAMPUS_BASE_URL`、`COURSE_CAMPUS_MODEL` 和可选 `COURSE_CAMPUS_KEY` 环境变量，页面仅显示配置地址和模型名。校园服务器保持待真实接入测试状态，后续依据校园实际接口完善验证。

　　调用链为 `web/model-settings.js` → `src/research_server.py` 的 `/api/model/*` → 原有连接模块。`GET settings/profiles/readiness` 查询公开配置和连接状态，`POST configure/models/select/probe/probe-vision/balance/clear` 处理配置及显式验证。研究报告仍通过 `prepare` 建立框架，素材整理与人工复核独立运行；连接就绪后，算法组确定的研究模型再按报告接口接入。

### 报告结构

快照报告：`course_content.teaching_content` 为授课内容，`teacher_observation` 为可观察教师表现；`danmaku_summary` 为弹幕整体内容；`overall_state` 预留整体状态及依据；`evidence` 保存证据，`review_notes` 保存待核事项。

片段报告：`overall_content` 分为授课内容和教师表现；`danmaku_feedback` 为弹幕反馈；`evidence_frame_ids` 关联本片段快照；`limitations` 保存范围说明。

输入保留标题、绝对时间、总时长、相对位置计算条件、辅助字段开关和输入版本。后续模型接口应返回固定结构及真实模型版本；模型执行失败时保留明确状态。人工修订保存独立原文与变更原因，经过算法组裁决后再决定是否纳入数据集。

`POST /api/tasks` 建立任务；`POST /api/task/<id>/upload` 导入视频、字幕或原图；`configure` 保存片段与辅助开关；`prepare` 建立报告框架；`review` 保存人工修订；`GET .../export` 与 `.../html` 导出完整记录或阅读版；`pair` 生成短期采集配对；`POST /api/capture` 接收原生截图。

## 本轮验证与待验证事项

2026年9月29日，66项Python单元和本地HTTP测试通过，其中8项新增测试覆盖字幕覆盖率、时间范围、连续片段、原图保真、报告待接入状态、输入更新失效、修订来源保护、原生采集来源校验、配对凭据和旧平台接口退出。3个新增JavaScript文件通过语法检查。

　　同日恢复模型选择后，70项Python测试通过，新增4项覆盖模型接口会话保护、密钥隔离、配置验证、模型切换后的就绪状态失效、三种运行方式随任务保存及保留报告待接入状态；模型设置页面通过JavaScript语法检查。外部服务响应使用测试替身，验证记录代表工程行为，真实账户调用与校园推理效果另行记录。

浏览器使用仓库15.416667秒合成视频完成任务创建、视频上传、两条字幕导入、100%时间覆盖显示、原图上传和报告框架建立。该记录检验工程流程，真实B站字幕质量和采集成功率另行验证。

B站登录后的字幕接口、扩展在真实播放器中的字幕选择器、弹幕加载时机、缩放与页面遮挡仍需在用户Chrome或Edge中完成联调。当前工具只能控制应用内浏览器，B站页面未成功加载，故本轮未将原生页面采集记为端到端实测完成。

本轮未训练模型、冻结类别或生成自动研究结论。算法组继续负责从数据集设计到训练与评测的核心工作；应用组负责采集工具、证据呈现、接口适配和后续应用端增强。
